# Lightning AI

> Lightning AI is a platform for building AI: develop in a cloud Studio, train at scale, and deploy models as APIs.

## Key Information

Products: Studios, Training, Inference/Deployments, Data. Open-source libraries: PyTorch Lightning, Fabric, LitServe, LitData.
Website: https://lightning.ai. Docs: https://lightning.ai/docs

## Open source docs

One entry point per open-source library from the team behind PyTorch Lightning:

- [PyTorch Lightning](https://lightning.ai/docs/pytorch/stable): Finetune and pretrain AI models. Focus on science, not engineering.
- [Lightning Fabric](https://lightning.ai/docs/fabric/stable): Scale foundation models to 1000s of GPUs with expert-level control.
- [TorchMetrics](https://lightning.ai/docs/torchmetrics/stable): 90+ PyTorch metrics, optimized for distributed training.
- [Thunder](https://lightning.ai/docs/thunder/latest): Compiler for PyTorch: make PyTorch models faster.
- [LitServe](https://lightning.ai/docs/litserve): Easily serve AI models, Lightning fast.
- [LitData](https://lightning.ai/docs/litdata): Stream and process datasets at scale.
- [LitGPT](https://github.com/Lightning-AI/litgpt): 20+ high-performance LLMs with recipes to pretrain, finetune and deploy at scale.

## Searching the docs

- Start at the worlds registry: https://lightning.ai/api/v1/docs/worlds — a JSON list of every docs "world" (Platform + the libraries). Each world has a `root` (or `multiRoot` with versioned `roots`); each root carries a `urlPrefix` (public URL, includes `/docs`) and a `manifestUrl`.
- Pick a root and fetch its `manifestUrl` (e.g. https://lightning.ai/docs/manifests/platform.json) — it lists every page's path + a brief description plus the navigation tree (paths are world-relative). It can be large, so grep it for keywords to find the relevant pages rather than reading it whole.
- A page's URL is `<urlPrefix>/<world-relative-path>`; append `.json` for its content or `.md` for plain markdown (e.g. https://lightning.ai/docs/platform/train.md), also reachable by requesting the page with `Accept: text/markdown`. Links inside a `.md` page point at sibling `.md` files; follow them to navigate.
- Manifest entries may carry `restrictTo` (billing tier) or `featureFlags`; those pages apply only to specific users — don't surface or recommend them to a general user unless they ask about that tier/feature.
